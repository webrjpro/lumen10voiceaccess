# Technical release integrity

Original contributions: Carlos Antonio de Oliveira Piquet. One component: mod_lumen10voiceaccess.

The current installable ZIP, SHA-256, exact source manifest and detached Ed25519 signature are in packages. The public key is included. Private signing keys, provider credentials, Moodle configuration, databases and participant records are excluded.

The signature verifies the release against the technical key. It is not an INPI software registration, ICP-Brasil certificate or independent proof of authorship, and does not restrict rights granted by GNU GPL v3 or later. Keep an independently trusted copy of the public-key fingerprint.
